# 威胁模型

[English](threat-model.md) | **简体中文**

Palette 防什么、假设什么，以及它刻意不做什么。

## 信任

**永远不可信：**

* Agent 发来的任何东西——参数、坐标、文本、`request_id`，以及它关于自己权限的任何主张；
* 客户机操作系统及其中的每一个应用，包括试图攻击宿主机的客户机；
* 网页、文档，以及屏幕上任何可见文本；
* 未来的远程客户端。

**可信：**

* 运维编写的 profile、权限策略、本服务；
* 运维安装的 QEMU 构建，以及宿主操作系统。

屏幕内容是**数据**。屏幕上出现的一条指令，不是来自运维的指令，服务里没有任何一处会把它当成
指令对待。

## 边界与强制手段

| 风险 | 控制手段 |
| --- | --- |
| Agent 借管理接口触达宿主机 | 没有 `qmp_execute`、没有 HMP、没有通用 monitor 透传。命令允许列表是一个经过审查的常量，未知命令在本地就被拒绝，根本不会发出去 |
| 管理通道被别处访问 | QMP 跑在服务自己启动的子进程的私有管道上。没有 TCP 监听、没有 VNC、没有 SPICE、没有显示窗口 |
| 读写宿主机文件 | 任何参数都不会是宿主机路径。镜像、frame、日志与审计都从可信配置和生成的标识组合而成，然后经词法与链接两重检查收敛到 `runtime_root` 之内 |
| 客户机攻击宿主机 | QEMU 以非提权身份运行，设备集最小化，无共享目录、无透传，环境变量走白名单。请保持更新；固定版本不是跳过安全补丁的理由 |
| 通过共享通道泄漏数据 | 无 9p、无 virtiofs、无 SMB、无双向剪贴板、无宿主设备直通 |
| 触达宿主机或内网 | 默认完全没有网卡。受限 user networking 不是出站策略，也不会被当作出站策略提供 |
| 资源耗尽 | 动作队列有界、文本长度与输入预算有界、动作时长有界、图像尺寸与像素数有界、审计文件增长有界，并对 QEMU 进程设置宿主侧内存上限 |
| 两个写入者争抢同一个桌面 | 每台 VM 一个动作队列、一个控制权代次、没有额外的可写输入路径 |
| 日志泄漏秘密 | 审计只记动作类型、长度、时序和结果。绝不记输入正文、绝不记启动参数、绝不记截图、绝不记宿主机路径 |
| 重置删错东西 | 删除要求存在 manifest，且路径解析后必须落在 `runtime_root` 之内；并拒绝跟随链接 |
| 页面诱导 Agent 提权 | 权限来自可信 profile。没有任何工具能授予权限，也没有任何 Agent 能提供的路径会变成文件或命令 |

## Palette 不防什么

* **已经以同一宿主用户身份运行的恶意进程。** 任何能读这个用户文件的东西，都能读运行目录，
  也能调用同一个 QEMU 可执行文件。更强的隔离需要独立的低权限服务账户和操作系统沙箱——那是合理
  的下一步，不是本 MVP 自称具备的能力。
* **多租户。** 一个服务、一个运维、同一时刻一台 VM。没有按租户的授权、配额或审计隔离。
* **真实恶意代码。** 客户机是一台虚拟机，不是一份证明。请把它当作遏制手段，而不是恶意代码沙箱。
* **截图保持私密。** 截图会送到客户端所配置的那个模型。不落盘不等于没人看过。请使用测试账号和
  不含敏感资料的模板，并假定屏幕上的一切都已经到达模型。
* **远程传输。** 本构建只提供 stdio。Streamable HTTP 需要 TLS、身份认证、按 VM 的授权、严格的
  `Origin`/`Host` 校验、消息限额、限流、会话过期与审计——而且 MCP session id 不是身份。
* **有保证的 exactly-once。** 去重是进程内、有界的。在发出输入与记录结果之间崩溃，会留下一个
  结果不明的动作；服务会报告 `unknown`，而不是重放它。
* **把工具注解当授权。** `readOnlyHint` 和 `destructiveHint` 帮助客户端呈现决策。它们不替代
  任何东西：每一次调用都在服务端检查。

## 服务确实给出的保证

* 输入绝不会被发送到请求所指之外的实例，也不会基于已被其他动作作废的 frame 发送。
* 超时、响应丢失或后续截图失败，**绝不**触发自动重放。回执会写 `unknown`，是否再试一次由调用方
  决定。
* 只有在服务真的确认过之后，释放才会被报告为已确认。通道已死时产出的是“无法确认”，绝不是一句
  成功声明。
* 清理只触及 manifest 中登记、并被限制在运行根目录内的对象。
* `system_reset` 永远不会被当作重置：干净重置替换可写层，并让基础镜像逐字节保持不变。
